Project Synopsis:

This project aims to automate basic school administrative operations like student admission, teacher management, class attendance, fee collection, and library inventory. 
It is developed in Python (for logic) and MySQL (for database storage).

Platform & Requirements:

Frontend: Python 3.x (IDLE)

Backend: MySQL 5.x

Connector: mysql.connector

Operating System: Windows/Linux

Packages: mysql-connector-python

Project Objectives:

Manage student and teacher databases efficiently
Maintain records for attendance, fees, and library books
Provide CRUD operations (Create, Read, Update, Delete) for each module
